# Leash web app

Next.js dashboard and AI agent API for [Leash](../README.md).

```bash
npm install
cp .env.example .env.local   # fill in the values (see the main README)
npm run dev                  # http://localhost:3000
npm run codegen              # regenerate src/generated/leash from idl/leash.json
```

- `src/app/api/agent/`: agent endpoint (Groq + tools, owner signature check)
- `src/lib/server/`: server-only code: agent signer, Solana tools, LLM, auth
- `src/components/`: dashboard UI
- `src/generated/leash/`: typed program client generated by Codama. Don't edit by hand.
